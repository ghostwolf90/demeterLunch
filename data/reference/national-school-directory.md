# 全臺學校備用名冊

教育部統計處 115 學年度名錄，於 2026-10-23 下載。依政府資料開放授權條款－第1版使用：<https://data.gov.tw/license>。

本名冊目前僅供後續擴張盤點，未接入公開學校選單、孩子學校設定、SQLite、D1、菜單抓取、提醒或部署流程。所有紀錄均為 `enabled: false`、`mealDataStatus: not_checked`。已有臺中服務繼續使用既有名冊。

## 範圍與計數

- 22 縣市，4,129 筆學段紀錄，3,856 個不重複教育部學校代碼。
- 國小 2,653 筆、國中 970 筆、高中職 506 筆，包含來源所列的附設部與進修學校。
- 同校可能有多個學段，附設部不是另一所獨立學校；不得將 4,129 解讀為獨立學校數。
- 這是官方五份名錄的年度快照，不保證包含另列的特殊教育學校、籌備處、所有分校或名錄公布後的異動，也不代表各校均有午餐服務。
- 名稱、地址、電話與網站保留來源內容，不另猜測供餐狀態或學校狀態。

## 來源

1. 國民小學名錄：<https://data.gov.tw/dataset/6087>
2. 國民中學名錄：<https://data.gov.tw/dataset/6088>
3. 一般高級中等學校名錄：<https://data.gov.tw/dataset/6089>
4. 附設國小部名錄：<https://data.gov.tw/dataset/28591>
5. 附設國中部名錄：<https://data.gov.tw/dataset/28590>

`national-school-directory.json` 記錄各來源網址、SHA-256、實際下載時間、來源筆數與縣市統計。原始 JSON 保存在旁邊的 `national-school-directory-raw/`。國中及附設國中部的官方資源包含歷年資料，整理時只選取指定學年度。

## 更新與啟用

使用 Python 3 與系統 curl 執行：

```sh
python3 scripts/fetch_national_school_directory.py --year 115
```

每次請求間隔一秒、逾時 30 秒、最多重試一次，維持 TLS 憑證驗證。全部來源下載且驗證成功後才原子替換整理名冊；相同內容不改寫名冊。原始檔以內容雜湊命名保存。

教育部代碼是字串，可能包含前導零或英文字母；不得轉成整數，也不得當作校園食材平臺 School ID。日後啟用前須另外核對兩套識別碼與同日菜單可用性，再明確加入既有服務名冊。不可只依同名學校自動配對或批量開啟提醒。
