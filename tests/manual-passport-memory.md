# 一口護照人工驗證

自動驗證：Python 全套、Worker 測試、TypeScript、前端語法與正式建置。依專案限制，未使用瀏覽器自動化。

人工請檢查：

- 手機與桌面：登入後選自己的孩子與有同日菜單的日期，只留孩子原話即可儲存。
- 原話／相遇／家長筆記三個入口可切換；切換不清空已填內容，空白紀錄不能儲存。
- 成功後出現剛存好的卡片；原話與家長筆記分開，未填接觸方式不推論成吃過。
- 從最近片刻或全部紀錄進入修改；Escape、取消、背景點擊可離開；操作失敗保留輸入。
- 刪除須再按「確定刪除」，完成後相關畫面重新讀取，不留下舊卡片。
- Tab 可走遍編輯面板，開啟焦點在原話，關閉回到觸發處；完成更新後焦點回到最近片刻或紀錄標題。
- 多孩家庭切換時不短暫顯示另一位孩子的紀錄；慢速連線下也不被較晚返回的舊回應覆蓋。
- 舊紀錄保持原日期與來源缺漏，不因孩子轉學套用現在學校。
- 登出後私人卡片消失。私人資料不寫入 localStorage/sessionStorage，不傳給分析事件。

最近片刻只呈現最近三筆紀錄，其他紀錄由「查看全部」進入；不再另外顯示每週回顧。
